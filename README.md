# QuickBite Chatbot

AI powered conversational food delivery chatbot developed.

## Project Status

Initial project setup

## Architecture

User → Input Parser → Rule-Based NLP → Dispatcher → State Manager
→ Handler → Mock Backend → Response Generator

## Core Features

- Food ordering
- Order tracking
- Order cancellation
- Fallback handling
- Multi-turn conversation state
- Hybrid rule based + LLM NLP

## Tech Stack

- Python(3.11.6)
- Regex / rule-based NLP
- Local LLM via Ollama
- pytest
